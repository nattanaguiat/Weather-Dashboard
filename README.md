# Weather Dashboard

## Description

With this application, the user is allow to search and check the 5 day forecast of a city as a great way to find a few variables of the weather of each one.

## Installation

By using the technollogy of typescript, the right way to get the app working will be by running the commands npm install for the dependencies, npm run build to have the compiler ready, and then just running the server and the client(npm run start && npm run dev).

## Usage

![WeatherDashboard](./assets/screenshots/weather%20dashboard%20ss.jpg)

On this application, the user cand search for a city on the "Search Bar" and by clicking on the button, the city is going to be released on the screen with the current weather and a 5 Day forcast will populate.

The city will be saved en the side and the user is allow to delete it from the saved cities.
